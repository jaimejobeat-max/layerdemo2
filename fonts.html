적용 방법

01번 Circular를 쓰려면 plusjun.com의 /fonts/804962159-lineto-circular-book-s.woff를 새 사이트 assets/fonts/로 옮기고 @font-face로 선언합니다. Lineto 웹폰트 라이선스가 도메인 단위인지 확인이 필요하고, Book 한 가지만 있어서 제목을 굵게 하려면 Bold를 추가 구매해야 합니다.

@font-face { font-family: "LL Circular"; src: url("../assets/fonts/circular-book.woff") format("woff"); font-weight: 400; }
:root { --sans: "LL Circular", "Figtree", "Helvetica Neue", Arial, "Pretendard", sans-serif; }
body { text-transform: none; }
.slide__eyebrow, .slide__type, .sidenav__link { font-weight: 400; letter-spacing: 0; }
.slide__title { font-weight: 500; font-size: 44px; letter-spacing: 0; line-height: 1; }

Google Fonts 안(02~10)은 <head>에 링크 한 줄과 --sans 변수 교체로 끝납니다. 어떤 안이든 위 네 줄(대문자 해제 · 웨이트 · 자간 · 제목 크기)은 같이 바꿔야 plusjun.com의 인상이 납니다.
